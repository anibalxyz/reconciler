# Contributing to Reconciler

Welcome! This guide will help you get started contributing to the project.

More detailed conventions for commits, branches, PRs, testing, releases, and issues live in an agent-first flow built on [AGENTS.md](./AGENTS.md) + [docs/skills/](docs/skills/).
The project [documentation](./docs/README.md), including the agent skills, is perfectly readable naturaly, though it is recommended to scan them with an agent and ask it to explain any convention.

## Getting Started

Before contributing, make sure you can run the project by following the [Getting Started](/README.md#getting-started) section in the README.

## Contributing Code

The details for each step below (branch naming, commit format, PR workflow) are documented in [docs/skills/](./docs/skills/).

1. Create or identify an issue to work on. It is the recommended and most comfortable approach, but optional for small changes
2. Create a branch from `main`
3. Make your changes following the conventions in [AGENTS.md](./AGENTS.md) and [documentation](./docs/README.md)
4. Push your branch and open a pull request to `main`
